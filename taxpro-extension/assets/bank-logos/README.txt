# TaxPro Extension — Logo qovluğu

31 portalın loqoları üçün yer tutucudur. Hazırda backend-də `logo_url` dəyərləri
boş olduğundan UI hərf-avatar (portal adının ilk hərfləri) istifadə edir.

Loqolar gələcəkdə bura əlavə oluna bilər: `popup/popup.js` `site-avatar`
bölməsindən `p.logo_url` dəyərinə keçid etmək kifayətdir.
