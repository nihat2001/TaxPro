# TaxPro Backend — Fayl Strukturu

```
taxpro-backend/
├── app/
│   ├── api/
│   │   └── v1/
│   │       ├── endpoints/
│   │       │   ├── profiles.py          # Profil CRUD (Deterministik)
│   │       │   ├── portals.py           # Portal siyahısı & Auto-fill payload (Deterministik)
│   │       │   ├── import_excel.py      # Standart Excel (Deterministik) + Ağıllı idxal (AI)
│   │       │   ├── bank_statements.py   # Bank çıxarışı analizi (AI)
│   │       │   └── chat.py              # RAG çat (profile_data_retriever_agent)
│   │       └── api.py                   # APIRouter birləşməsi
│   │
│   ├── core/
│   │   ├── config.py                    # Env dəyişənləri (DB_URL, API Keys, ENCRYPTION_KEY)
│   │   ├── database.py                  # Asinxron SQLAlchemy Engine & Session
│   │   ├── security.py                  # PIN/PUK şifrələmə (Fernet/AES) köməkçiləri
│   │   └── logging.py                   # Mərkəzləşdirilmiş logging konfiqurasiyası
│   │
│   ├── models/
│   │   ├── profile.py                   # Profile ORM modeli
│   │   ├── portal.py                    # Portal ORM modeli
│   │   └── vector_store.py              # pgvector Embeddings modeli
│   │
│   ├── schemas/
│   │   ├── profile.py                   # Pydantic v2 validasiya modelləri
│   │   ├── portal.py                    # Portal və Auto-fill şablonları
│   │   └── chat.py                      # Çat və Agent cavab şablonları
│   │
│   ├── services/
│   │   ├── deterministic/               # AI-SIZ İŞLƏYƏN HİSSƏ
│   │   │   ├── excel_parser.py          # Standart Excel oxuyucu (Pandas/OpenPyXL)
│   │   │   ├── profile_service.py       # Baza ilə birbaşa CRUD funksiyaları
│   │   │   └── autofill_service.py      # Auto-fill məlumatı hazırlayan servis
│   │   │
│   │   └── ai/                          # AI / LANGGRAPH HİSSƏSİ
│   │       ├── agents/
│   │       │   ├── supervisor.py        # LangGraph Supervisor Agent
│   │       │   ├── parser.py            # unstructured_parser_agent
│   │       │   ├── bank_vat.py          # bank_vat_agent
│   │       │   └── retriever.py         # profile_data_retriever_agent
│   │       ├── tools/
│   │       │   └── db_retriever_tool.py # PostgreSQL pgvector / SQL search tool
│   │       ├── state.py                 # Nested TypedDict state tərifi
│   │       └── graph.py                 # LangGraph State & Conditional Routing (goto)
│   │
│   └── main.py                          # FastAPI giriş nöqtəsi (CORS enabled)
│
├── tests/
│   ├── test_profiles.py
│   ├── test_autofill.py
│   └── test_agents.py
│
├── alembic/                             # DB miqrasiyaları
│   └── versions/
│
├── .env
├── .env.example
├── requirements.txt
├── alembic.ini
└── README.md
```
