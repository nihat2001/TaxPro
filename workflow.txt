# TaxPro — Workflow Diaqramları

## 1. Ümumi Sistem Axını

```mermaid
flowchart TD
    EXT["Chrome Extension / Frontend"]

    EXT --> A["Portallar & Redaktə"]
    EXT --> B["Excel & Bank Çıxarışı"]
    EXT --> C["AI Çat (RAG)"]

    A --> A1["Sayta klik → rəsmi portal yeni tabda açılır"]
    A --> A2["Profil Yarat/Redaktə → DB-yə yazılır"]
    A --> A3["'Doldur' düyməsi → Extension input-lara köçürür"]

    B --> B1{"Excel standart formatdadır?"}
    B1 -->|Bəli| B2["Deterministik oxuma → DB"]
    B1 -->|Xeyr| B3["unstructured_parser_agent → DB"]
    B --> B4["Bank çıxarışı yükləndi"]
    B4 --> B5["bank_vat_agent → Analiz & Kateqoriyalaşdırma"]

    C --> C1["PostgreSQL (pgvector) üzrə axtarış"]
    C1 --> C2["100% dəqiq, DB-əsaslı cavab"]
```

## 2. Deterministik vs AI Router

```mermaid
flowchart TD
    IN["Məlumat / Sorğu gəlir"]
    IN --> Q{"Standart əməliyyatdır?"}

    Q -->|Bəli| DET["DETERMİNİSTİK REJİM (AI çağırılmır ❌)"]
    Q -->|Xeyr| AI["AI / LANGGRAPH REJİMİ (Supervisor işə düşür 🤖)"]

    DET --> D1["Standart CRUD (Profile Create/Update)"]
    DET --> D2["Standart Excel (səliqəli fayl)"]

    AI --> SUP["supervisor_agent"]
    SUP -->|goto| P1["unstructured_parser_agent"]
    SUP -->|goto| P2["bank_vat_agent"]
    SUP -->|goto| P3["profile_data_retriever_agent"]
    P1 -->|goto supervisor| SUP
    P2 -->|goto supervisor| SUP
    P3 -->|goto supervisor| SUP

    D1 --> DB[("PostgreSQL")]
    D2 --> DB
    SUP --> DB

    DB --> OUT["Təmiz JSON Cavabı"]
    OUT --> EXT["Google Chrome Extension"]
```

## 3. LangGraph Supervisor Daxili Axını

```mermaid
sequenceDiagram
    participant U as İstifadəçi (Çat)
    participant S as supervisor_agent
    participant W as Worker Agent
    participant DB as PostgreSQL / pgvector

    U->>S: Sorğu (məs. "Əhmədin Asan ID-si nədir?")
    S->>S: State (TypedDict) yenilənir, attempt_count++
    S->>W: Command(goto="profile_data_retriever_agent")
    W->>DB: pgvector / SQL sorğusu
    DB-->>W: Nəticə
    alt Uğurlu
        W-->>S: Command(goto="supervisor")
        S-->>U: Dəqiq cavab (JSON)
    else Uğursuz və cəhd < max
        W-->>S: Command(goto="supervisor", retry=true)
        S->>W: Yenidən cəhd
    else Cəhd == max
        S-->>U: error_handler cavabı
    end
    Note over S,W: interrupt_before=["sensitive_write_node"]<br/>həssas yazmalarda istifadəçi təsdiqi gözlənilir
```

## 4. Auto-fill Axını (Extension tərəfi)

```mermaid
sequenceDiagram
    participant User as İstifadəçi
    participant Ext as Chrome Extension
    participant API as TaxPro Backend
    participant Site as Rəsmi Bank/Vergi Saytı

    User->>Ext: Profil seçir, sayta klikləyir
    Ext->>Site: Yeni tabda rəsmi sayt açılır
    User->>Ext: "Doldur" düyməsinə basır
    Ext->>API: GET /autofill/{profile_id}/{portal_id}
    API-->>Ext: JSON (field → value)
    Ext->>Site: content script ilə input-lara yazır
```
